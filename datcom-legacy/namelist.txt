# Simplified DATCOM Namelist Variables Reference
# Extracted from namelist.pdf
# Format: VARIABLE_NAME - Description (Units: unit_type)
============================================================

NAMELIST ASYFLP - Asymmetrical Control Deflection Unit
------------------------------------------------------
DELTAL - deflection angle for left hand plain flap aileron (deg)
DELTAR - deflection angle for right hand plain flap aileron (deg)
DELTAD - projected height of deflector, spoiler-slot deflector control (fraction of chord)
DELTAS - projected height of spoiler, flap/plug spoiler and spoiler-slot deflector control (fraction of chord)
XSOC - distance from wing leading edge to spoiler lip (fraction of chord)
HSOC - projected height of spoiler measured from airfoil mean line (fraction of chord)
STYPE - spoiler type (=1.0 flap, =2.0 plug, =3.0 spoiler-slot-deflection, =4.0 plain flap, =5.0 differential tail)
XSPRME - distance from wing leading edge to spoiler hinge line (fraction of chord)
NDELTA - number of control deflection angles (max 9)
CHRDFI - aileron chord at inboard edge (length)
CHRDFO - aileron chord at outboard edge (length)
SPANFI - span location of inboard edge of flap/spoiler control (length)
SPANFO - span location of outboard edge of flap/spoiler control (length)
PHETE - tangent of airfoil trailing edge angle

NAMELIST BODY - Body Geometry Data
----------------------------------
NX - number of longitudinal body stations (max 20)
X - longitudinal distance measured from arbitrary location (length, array[20])
S - cross sectional area (area, array[20])
P - periphery at station x(i) (length, array[20])
R - planform half width (length, array[20])
ZU - z-coordinate at upper body surface (length, array[20])
ZL - z-coordinate at lower body surface (length, array[20])
BNOSE - nose type (=1 conical, =2 ogive)
BTAIL - tail type (=1 conical, =2 ogive)
BLN - length of body nose (length)
BLA - length of cylindrical afterbody segment (length)
DS - nose bluntness diameter (length)
ITYPE - wing type (=1 straight/no area rule, =2 swept/no area rule, =3 swept/area rule)
METHOD - analysis method (=1 existing, =2 Jorgensen)

NAMELIST CONTAB - Control Tabs
-------------------------------
TTYPE - control tab type (=1 tab control, =2 trim tab, =3 both)
CFITC - inboard chord, control tab
CFOTC - outboard chord, control tab
CFITT - inboard chord, trim tab
CFOTT - outboard chord, trim tab
BITC - inboard span location, control tab
BOTC - outboard span location, control tab
BITT - inboard span location, trim tab
BOTT - outboard span location, trim tab
B1,B2,B3,B4,D1,D2,D3,GCMAX,KS,RL,BGR,DELR - control system parameters (see Table 11)

NAMELIST EXPR - Experimental Data Input
-----------------------------------------
CDB,CLB,CMB,CLAB,CMAB - body aerodynamic coefficients (array[20])
CDW,CLW,CMW,CLAW,CMAW - wing aerodynamic coefficients (array[20])
CDH,CLH,CMH,CLAH,CMAH - horizontal tail aerodynamic coefficients (array[20])
CDWB,CLWB,CMWB,CLAWB,CMAWB - wing-body aerodynamic coefficients (array[20])
QOQINF,EPSLON,DEODA,CDV - additional experimental data (array[20])
ALPOW,ALPLW,ALPOH,ALPLH - angle of attack limits
ACLMW,CLMW,ACLMH,CLMH - additional experimental parameters

NAMELIST FLTCON - Flight Conditions
-----------------------------------
NMACH - number of Mach numbers/velocities (max 20)
MACH - freestream Mach number (array[20])
VINF - freestream speed (length/time, array[20])
NALPHA - number of angles of attack (max 20)
ALSCHD - angle of attack values (deg, array[20])
RNNUB - Reynolds number per unit length (1/length, array[20])
NALT - number of atmospheric conditions (max 20)
ALT - geometric altitudes (array[20])
PINF - freestream static pressure (pressure, array[20])
TINF - freestream temperature (temp, array[20])
HYPERS - hypersonic analysis flag (.TRUE./.FALSE.)
STMACH - upper limit for subsonic analysis (default 0.6)
TSMACH - lower limit for supersonic analysis (default 1.4)
TR - drag due to lift transition flag (=0.0 no transition, =1.0 transition strips)
WT - vehicle weight (force)
GAMMA - flight path angle (deg)
LOOP - program looping control (=1 vary alt/Mach, =2 vary Mach, =3 vary alt)

NAMELIST GRNDEF - Ground Effect
-------------------------------
NGH - number of ground heights
GRDHT - ground heights (array[10])

NAMELIST HYPEFF - Flap Control at Hypersonic Speeds
---------------------------------------------------
ALITD - altitude (length)
XHL - distance to control hinge line from leading edge (length)
TWOTI - ratio of wall temperature to freestream static temperature
CF - control chord length (length)
LAMNR - boundary layer flag at hinge line (.TRUE. laminar, .FALSE. turbulent)
HNDLTA - number of flap deflection angles (max 10)
HDELTA - control deflection angle (deg, array[10])

---------------------------------------

JETOTP - jet exit total pressure (pressure)
AMBSTP - ambient static pressure (pressure)

---------------------------------------------------------------
TOVC - maximum airfoil section thickness (fraction of chord)

XOVC - chord location of maximum airfoil thickness (fraction of chord)
CLI - airfoil section design lift coefficient
ALPHAI - angle of attack at section design lift coeff. (deg)
CLALPA - airfoil section lift curve slope per degree (array[20])
CLMAX - airfoil section maximum lift coefficient (array[20])
CAMBER - cambered airfoil section flag
CM0 - section zero lift pitching moment
CMO - same as CM0
XOVCO - (x/c)max for outboard panel
TOVCO - thickness ratio for outboard panel (fraction of chord)
CMOT - pitching moment coeff at zero lift, outboard panel
CM0T - same as CMOT
TCEFF - planform effective thickness ratio (fraction of chord)
KSHARP - wave drag factor for sharp-nose airfoil
CLMAXL - airfoil maximum lift coeff. at M=0
SLOPE - airfoil surface slope
CLAMO - airfoil section lift curve slope at M=0 per deg.
CLAM0 - same as CLAMO
ARCL - aspect ratio classification (see Table 6)
XAC - section aerodynamic center (fraction of chord)
DWASH - subsonic downwash method flag (=1,2,3 DATCOM methods)
YCM - airfoil maximum camber (fraction of chord)
CLD - conical camber design lift coeff.
TYPEIN - type of airfoil section coordinates (=1 upper/lower, =2 mean line/thickness)
LERI - airfoil leading edge radius (fraction of chord)
LERO - airfoil leading edge radius for outboard panel (fraction of chord)
